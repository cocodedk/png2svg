شروع سریع

یک وابستگی، یک فرمان

از گیت‌هاب نصب کنید و SVG را کنار PNG ورودی بسازید.

$ python -m pip install git+https://github.com/cocodedk/png2svg.git
$ png2svg icon.png
$ png2svg logo.png --web --width 256

مرز ابزار را بشناسید

این ابزار پیکسل‌ها را ردیابی می‌کند؛ برای عکس، منحنی بزیهٔ نرم نمی‌سازد. برای یک لوگوی پیکسلی واضح، همین تفاوت مزیت اصلی است.
