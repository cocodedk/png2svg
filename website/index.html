WHAT IT DOES

Honest vectors, predictable output

01

Exact by default

Color and alpha stay intact. Transparent pixels create no geometry.

02

Actually vector-only

No base64 payload, embedded PNG, browser trick, or native tracer.

03

Built for the web

--web caps tracing detail and reduces colors for smaller logos and favicons.

QUICK START

One dependency. One command.

Install from GitHub, then write an SVG beside the source PNG.

$ python -m pip install git+https://github.com/cocodedk/png2svg.git
$ png2svg icon.png
$ png2svg logo.png --web --width 256

Know the edge

This is lossless pixel tracing, not smooth Bézier tracing for photographs. For a crisp pixel logo, that distinction is the feature.
